## 🛑 Root cause: environment network allowlist

Every listing site returns HTTP 403 with body `"Host not in allowlist"`. This is **not** bot protection on the sites themselves — it's **this Claude Code on the web environment's outbound network policy** refusing to forward traffic. The 403 comes from the egress proxy, before any packets reach the site.

But the immediate blocker is policy, not bot detection.

Steps:
1. Open https://code.claude.com → your environments
2. Find this environment (the one connected to `gpuranam/mostaccurateweather`)
3. Edit its **Network policy** to either:
